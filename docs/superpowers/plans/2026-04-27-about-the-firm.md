# About the Firm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a JAZA-branded "About the Firm" page (`/about-the-firm`) showing a 12-card leadership grid plus a per-member bio detail route (`/team/[slug]`), with a shared "Want us to help you explode profit?" CTA section.

**Architecture:** Next.js 16 App Router with one static listing route and one dynamic `[slug]` route pre-built via `generateStaticParams()`. A small `lib/team.ts` data module is the single source of truth for all twelve members. Pure presentation components live in `components/`. No new dependencies; brand tokens (`brand-yellow`, `brand-black`) and fonts (`font-heading`, `font-display`) already exist in `app/globals.css`.

**Tech Stack:** Next.js 16.2.4, React 19, TypeScript strict, Tailwind CSS v4, `next/image`, `next/link`. No test runner is installed in this project — verification is `next build` (catches type and import errors) plus visual smoke testing in the dev server.

**Spec:** `docs/superpowers/specs/2026-04-27-about-the-firm-design.md`

**Important Next.js 16 caveats** (verified against `node_modules/next/dist/docs/`):
- `params` in `app/.../[slug]/page.tsx` is `Promise<{ slug: string }>` — must be `await`-ed
- `PageProps<'/team/[slug]'>` is a globally available type generated by `next dev` / `next build` (no import)
- `notFound()` is from `next/navigation`

### Task 3: Create the `TeamCard` component

**Files:**
- Create: `components/team-card.tsx`

- [ ] **Step 1: Write `components/team-card.tsx`**

```tsx
import Image from "next/image";
import Link from "next/link";

import type { Member } from "@/lib/team";

const ACCENT_BORDER: Record<NonNullable<Member["accent"]>, string> = {
  purple: "border-purple-500",
};

function firstName(member: Member): string {
  if (!member.name) return "Name";
  const trimmed = member.name.trim();
  const space = trimmed.indexOf(" ");
  const first = space === -1 ? trimmed : trimmed.slice(0, space);
  return first.charAt(0) + first.slice(1).toLowerCase();
}

export function TeamCard({ member }: { member: Member }) {
  const borderClass = member.accent
    ? ACCENT_BORDER[member.accent]
    : "border-brand-black";
  const displayName = member.name ?? "NAME";
  const altText = member.name
    ? `${member.name} — ${member.role}`
    : "Team member placeholder";

  return (
    <article className="flex flex-col items-center text-center">
      <div
        className={`relative aspect-[4/5] w-full overflow-hidden border-2 ${borderClass} bg-neutral-200`}
      >
        {member.image ? (
          <Image
            src={member.image}
            alt={altText}
            fill
            sizes="(min-width: 1024px) 320px, (min-width: 640px) 50vw, 100vw"
            className="object-cover grayscale"
          />
        ) : (
          <span className="sr-only">{altText}</span>
        )}
      </div>
      <div className="h-3 w-full bg-brand-yellow" aria-hidden />

      <h3 className="mt-5 font-heading text-lg font-black uppercase tracking-wide text-brand-yellow md:text-xl">
        {displayName}
      </h3>
      <p className="mt-1 max-w-[20ch] text-xs font-bold uppercase tracking-wide text-brand-black md:text-sm">
        {member.role}
      </p>
      <Link
        href={`/team/${member.slug}`}
        className="mt-4 inline-flex items-center rounded-full bg-brand-yellow px-5 py-2 text-xs font-bold text-brand-black transition-transform hover:scale-[1.02] md:text-sm"
      >
        About {firstName(member)}
      </Link>
    </article>
  );
}
```

### Task 9: Create the `/team/[slug]` dynamic page and verify

**Files:**

- [ ] **Step 1: Write `app/team/[slug]/page.tsx`**

```tsx
import type { Metadata } from "next";
import { notFound } from "next/navigation";

import { AnnouncementBanner } from "@/components/announcement-banner";
import { CopyrightBar } from "@/components/copyright-bar";
import { ExplodeProfitCta } from "@/components/explode-profit-cta";
import { Footer } from "@/components/footer";
import { Navbar } from "@/components/navbar";
import { TeamBioHero } from "@/components/team-bio-hero";
import { getAllSlugs, getMember } from "@/lib/team";

type Params = Promise<{ slug: string }>;

export function generateStaticParams() {
  return getAllSlugs().map((slug) => ({ slug }));
}

export async function generateMetadata({
  params,
}: {
  params: Params;
}): Promise<Metadata> {
  const { slug } = await params;
  const member = getMember(slug);
  const name = member?.name ?? "Team Member";
  return {
    title: `${name} — JAZA Media`,
    description: member ? `${member.role}, JAZA Media` : "JAZA Media team member.",
  };
}

export default async function TeamMemberPage({ params }: { params: Params }) {
  const { slug } = await params;
  const member = getMember(slug);
  if (!member) notFound();

  const paragraphs = member.bio ?? [];

  return (
    <>
      <AnnouncementBanner />
      <Navbar />
      <main>
        <TeamBioHero member={member} />
        <section className="bg-white py-12 md:py-16">
          <div className="mx-auto max-w-3xl space-y-4 px-4 text-sm leading-relaxed text-brand-black md:text-base">
            {paragraphs.length > 0 ? (
              paragraphs.map((paragraph, i) => <p key={i}>{paragraph}</p>)
            ) : (
              <p className="text-text-muted">Bio coming soon.</p>
            )}
          </div>
        </section>
        <ExplodeProfitCta />
      </main>
      <Footer />
      <CopyrightBar />
    </>
  );
}
```
